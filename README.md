# 🤖 Asuna Core v2.0 — Персональний Локальний ШІ-Асистент

Asuna Core — це інтелектуальний персональний голосовий асистент, побудований на базі моделей Google Gemini та оптимізований для швидкої локальної роботи. Проєкт розроблений як розумний, емпатичний компаньйон із довгостроковою пам'яттю на базі текстової системи нотаток **Obsidian**. Асистент автоматично підлаштовується під ритм життя користувача, його інтереси та поточний стан, а взаємодія відбувається через кастомний графічний інтерфейс Electron.js.

---

## 🚀 Ключовий функціонал

1. **Голосове керування без затримок:** Використання оптимізованої локальної моделі `faster-whisper (small, int8)` для миттєвого розпізнавання українського мовлення з мікрофона (економить до 2 секунд на кожній репліці).
2. **Ультрашвидка генерація відповіді:** Робота на базі моделі `gemini-2.5-flash` (за замовчуванням), що забезпечує мінімальний показник затримки (Time-to-Speech) та безпомилково викликає локальні функції.
3. **Кришталево чиста українська вимова:** Інтеграція з голосовим рушієм `edge-tts` (голос `uk-UA-PolinaNeural`) із кастомним тюнінгом швидкості (`+15%`) та висоти тону (`+4Hz`) для живого, динамічного звучання. Вбудовано автоматичні текстові фільтри зачистки емодзі-описів (на кшталт *"усміхнене обличчя"*), які зазвичай ріжуть слух.
4. **Сувора лаконічність та чіткість:** Асуна адаптована під швидкий темп життя. Вона не будує довгих монологів, а відповідає коротко, влучно та ємно (строго 1–3 речення).
5. **Динамічний Function Calling (Виклик інструментів):** ШІ самостійно приймає рішення про маніпуляції з файлами на комп'ютері: створення нотаток, списків справ чи оновлення власної довгострокової пам'яті.
6. **Повна безпека та приватність:** Усі ваші особисті дані, профілі, інтереси та файли пам'яті залишаються виключно локально на вашому комп'ютері та ніколи не надсилаються в репозиторій завдяки налаштованому `.gitignore`.

## 📂 Структура директорій проекту

Для коректної роботи системи архітектура папок має відповідати наступному вигляду:

```text
Asuna v2/
│
│
├── Asuna/                      # Папка бекенду (Python-скрипти)
│   ├── main.py                 # Головне ядро системи
│   ├── bridge.py               # Місток інтеграції з графічним інтерфейсом Electron
│   ├── .env                    # Твій приватний файл конфігурації (API-ключі, ім'я)
│   └── voice.wav               # Тимчасовий файл запису голосу з мікрофона (очищується)
│
├── asuna_ui/                   # Графічний інтерфейс користувача (Electron.js додаток)
│
└── asuna_memory/               # База довгострокової пам'яті (Твій Obsidian Vault)
    ├── user_profile.md         # Дані про тебе (хобі, спорт, улюблені ігри, звички)
    ├── asuna_persona.md        # Характер, рольові параметри та правила поведінки Асуни
    ├── evolution_log.md        # Автоматичний лог фонових підсумків сесій розмов 
    └── asuna_workspace/        # Папка-"пісочниця" для створюваних нотаток
```

## ⚙️ Локальні інструменти пам'яті (Function Calling)

Асуна володіє набором інструментів для взаємодії з диском через методи класу:

- `create_workspace_file(filename, content)` — створює новий Markdown-файл у папці `asuna_memory/asuna_workspace/`. Автоматично зачищає хибні розширення та структурує контент за допомогою красивої розмітки.
    
- `edit_workspace_file(filename, content, mode="append")` — модифікує файли у вашій пісочниці в режимах дописування чи перезапису.
    
- `update_user_profile(fact)` — записує нові довгострокові знання про користувача безпосередньо у файл `user_profile.md` під час звичайної бесіди.
    
- `update_asuna_behavior(rule)` — фіксує ваші побажання щодо її поведінки (наприклад, заборона на довгі репліки) у файл `asuna_persona.md`.
    

## 🧠 Логіка перемикання режимів розмови

Асуна вміє розрізняти два типи стану користувача і адаптує свій алгоритм відповідей:

1. **Режим теревенів (Casual Chat):** Коли ви говорите про життя, хобі, ігри чи спорт. Асуна підтримує дружню розмову, говорить тепло, може ставити зустрічні запитання для розвитку діалогу та інколи вплітає короткі цікаві факти за темою розмови.
    
2. **Режим справи (Task Mode):** Коли ви даєте конкретну вказівку (налаштувати ОС, створити файл, структурувати інформацію). Асуна миттєво стає зосередженою, відсікає зайву інформацію, чітко виконує наказ, звітує про виконання в 1 короткому реченні й **суворо не ставить додаткових запитань в кінці**, щоб не відволікати від процесу.
    

## 🛠️ Покроковий гайд із встановлення та налаштування

### Крок 1: Встановлення системних залежностей (Windows)

Переконайтеся, що на вашому комп'ютері інстальовано:

1. **Python 3.10 або 3.11** (обов'язково позначте галочку _"Add Python to PATH"_ під час інсталяції).
    
2. **Node.js** (необхідний для запуску графічного вікна Electron у папці `asuna_ui`).
    
3. **FFmpeg** (необхідний для конвертації аудіопотоків. Переконайтеся, що шлях до папки `ffmpeg/bin` додано в системні змінні PATH Windows).
    

### Крок 2: Інсталяція Python бібліотек для бекенду

Відкрийте термінал у папці бекенду (`Asuna v2/Asuna`) та виконайте команду:

Bash

```
python -m pip install google-genai speechrecognition faster-whisper pygame edge-tts aiohttp requests python-dotenv
```

### Крок 3: Інсталяція залежностей інтерфейсу (UI)

Перейдіть у папку графічного інтерфейсу (`Asuna v2/asuna_ui`) через термінал та встановіть необхідні Node-модулі для Electron:

Bash

```
npm install
```

### Крок 4: Налаштування файлу конфігурації `.env`

У папці `Asuna/` знайдіть файл `.env.example`, перейменуйте його в **`.env`** та заповніть своїми даними:

Фрагмент коду

```
GEMINI_API_KEY=твої_персональний_ключ_gemini
OPENAI_API_KEY=твої_ключ_openai_якщо_треба

USER_NAME=ТвоєІм_я
VOICE_NAME=uk-UA-PolinaNeural
```

### Крок 5: Налаштування довгострокової пам'яті в Obsidian

1. Запустіть **Obsidian**.
    
2. Натисніть **"Open folder as vault"** та вкажіть шлях до папки пам'яті: `Asuna v2/asuna_memory`.
    
3. Створіть всередині три файли (`user_profile.md`, `asuna_persona.md`, `evolution_log.md`) та внутрішню папку `asuna_workspace`. Ви можете заповнити їх своїми звичками та хобі, спираючись на готові шаблони в репозиторії.
    

## 🏃 Запуск системи

Для максимальної зручності в папку asuna_ui додано автоматичний файл запуску **`Launch`** . Вам більше не потрібно відкривати кілька вікон терміналу та прописувати команди вручну.

1. Перейдіть у папку `Asuna v2/asuna_ui/`.
    
2. Просто двічі клацніть мишкою по файлу **`Launch.vbs`**.
    
3. Скрипт автоматично:
    
    - Запустить у фоновому режимі Python-сервер бекенду (`bridge.py`), який підтягне конфіги з `.env`.
        
    - Ініціює вікно графічного інтерфейсу Electron.js (`asuna_ui`), яке підключиться до містка.
        
4. Асуна готова до діалогу!

Щоб Асуна зберегла фоновий підсумок поточної зустрічі та оновила ваші довгострокові спогади, скажіть їй у мікрофон:

> **"Бувай"**, **"Вимкнись"** або **"Завершити роботу"**
